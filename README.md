# bizzsubsidy · 내 사업장 지원 찾기

업종·매출·직원 수를 넣으면 소상공인·소기업·중기업을 판정하고, 받을 수 있는 정부 지원과 지원 제외 업종을 보여주는 사이트입니다.
기업마당 API로 소상공인·개인사업자용 새 공고를 매일 아침 자동으로 가져옵니다.

- 사이트 주소: https://jungs311311.github.io/bizzsubsidy

## 파일 구성

| 파일 | 하는 일 |
|---|---|
| `index.html` | 사이트 화면 (규모 판정, 지원 목록, 제외 업종, 새 공고) |
| `data/notices.json` | 기업마당에서 받아 온 공고. 매일 자동으로 바뀜 |
| `scripts/fetch_bizinfo.py` | 기업마당 API를 불러 소상공인·개인사업자용 공고만 걸러 저장 |
| `scripts/watch_programs.py` | 사이트 지원 38개와 공고를 짝지어 접수 상태 계산, 새 공고·새 사업 알림 |
| `data/programs.json` | 지원별 공고 제목 짝짓기 규칙 (지원을 추가하면 여기도 추가) |
| `data/status.json` | 지원별 지금 접수 중인 공고 (매일 자동) |
| `data/seen.json` | 이미 알린 공고 목록 (같은 공고를 두 번 알리지 않음) |
| `scripts/fetch_sheet.py` | 구글 시트 '사업체 보조금 조건표'를 읽어 `data/sheet.json`으로 저장 |
| `data/sheet.json` | 시트에서 읽은 지원 문구·기준값·업종 규모 기준 (매일 자동). 사이트가 이 값으로 판정 |
| `.github/workflows/update.yml` | 매일 오전 6시쯤(한국시간) 위 스크립트를 실행하고, 알릴 게 있으면 GitHub 이슈를 만듦 |

## 처음 한 번만 할 일

1. **인증키 등록**: 저장소 `Settings` → `Secrets and variables` → `Actions` → `New repository secret`
   - Name: `BIZINFO_KEY`
   - Secret: 기업마당에서 받은 인증키
2. **사이트 켜기**: `Settings` → `Pages` → Source를 `Deploy from a branch`, Branch를 `main` / `(root)`로 두고 `Save`
3. **첫 실행**: `Actions` 탭 → `기업마당 공고 매일 갱신` → `Run workflow`

이후에는 매일 자동으로 갱신됩니다.

## 매일 자동으로 하는 일 (Claude 없이, 무료)

1. 기업마당 공고를 받아 사이트 아래 '새 공고' 칸을 갱신
2. 지원 38개마다 지금 접수 중인 공고를 찾아 카드에 "지금 접수 중 · D-n" 또는 "공고 없음" 표시
3. 38개 중 하나에 새 공고(변경 공고 포함)가 뜨거나, 38개에 없는 소상공인 대상 새 사업이 보이면 GitHub 이슈로 알림 (이슈에 @jungs311311을 불러서 메일이 옴)

금액·조건·제외 업종은 공고문 본문에만 있어서 자동으로 바뀌지 않아요. 이슈 알림이 오면 그 공고문을 보고 사이트 판정을 고치면 됩니다.

## 조건 고치기 (구글 시트)

- 시트: https://docs.google.com/spreadsheets/d/13crp7Mxc9zroQjgtSpVjeMvLAGd87dPfCFFQY2ZevDY (구글 드라이브 '사업체 보조금' 폴더)
- 시트는 '링크가 있는 모든 사용자 - 뷰어'로 공유해야 GitHub가 로그인 없이 읽어요.
- 탭: 지원 목록(문구·대상 규모·공고 찾기 단어·표시 여부, 새 줄을 넣으면 새 지원 카드), 기준값(판정 숫자), 업종 규모 기준, 변경 기록, 사용법
- 매일 아침 자동 실행 때 반영돼요. 바로 반영하려면 Actions → `기업마당 공고 매일 갱신` → `Run workflow`
- 시트를 못 읽거나 내용이 이상하면 지난번 값(없으면 `index.html`에 적힌 기본값)을 그대로 써요.
- 매주 월요일 아침 Claude가 시트 값을 공식 자료와 대조해 고치고 '변경 기록' 탭에 남겨요.

## 판정 기준

- 규모: 중소기업기본법 시행령 업종별 매출 기준, 소상공인기본법 상시근로자 기준
- 지원 제외 업종: 소상공인시장진흥공단 정책자금 지원 제외 업종 목록
- 금액·조건: 2026년 공개 공고 기준. 공고가 바뀌면 `index.html`의 지원 목록을 고칩니다.
